# Hassan GPT-6.1 Sol — دليل النشر

هذه حزمة موقع ويب متصلة بخادم Cloudflare Worker وWorkers AI. الاسم خاص بالمشروع، أما نموذج الإجابة الافتراضي فهو نموذج Llama مستضاف من Cloudflare وليس GPT رسميًا.

## النشر (يحتاج حساب Cloudflare)

1. نزّل Node.js على كمبيوتر، ثم فك ضغط الحزمة.
2. افتح الطرفية داخل مجلد المشروع وشغّل: `npm install`
3. سجّل الدخول: `npx wrangler login`
4. انشر الموقع والخادم: `npm run deploy`
5. افتح الرابط الذي يعرضه Wrangler، وغالبًا ينتهي بـ `workers.dev`.

يمكن أيضًا رفع المشروع إلى مستودع Git وربطه بـ Cloudflare Workers من لوحة التحكم، مع التأكد من أن إعدادات البناء تستخدم `npm install` وأن أمر النشر هو `npx wrangler deploy`.

## التكلفة والخصوصية

- استضافة الواجهة قد تكون مجانية ضمن حدود الخطة، لكن الاستدلال بالذكاء الاصطناعي يخضع لحصص وأسعار Cloudflare الحالية؛ لا يوجد ضمان بأن الاستخدام مجاني بلا حدود.
- لا تضع مفاتيح API في HTML أو JavaScript الخاص بالمتصفح. هذا المشروع يستخدم ربط Workers AI من الخادم بدلًا من كشف مفتاح.
- قبل مشاركة الرابط علنًا، أضف حماية من إساءة الاستخدام/تحديد معدل الطلبات. هذه النسخة الأولية لا تتضمن تسجيل دخول أو حصصًا لكل مستخدم.
- هذه الحزمة لا تنشر نفسها تلقائيًا؛ يجب أن تسجل الدخول إلى حسابك وتنفذ خطوات النشر.

## الملفات
- `public/index.html`: واجهة الموقع.
- `src/index.js`: واجهة API التي تتحقق من المدخلات وتتصل بالنموذج.
- `wrangler.jsonc`: إعدادات النشر وربط Workers AI.
